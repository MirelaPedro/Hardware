# Hardware 
Este é o repositório que salvo todos os trabalhos/projetos realizados em matérias ligadas ao hardware.

## Projetos
### Calculadora Digital
O referido trabalho foi desenvolvido com o objetivo de projetar uma calculadora digital que realize as operações mais básicas da matemática (soma, subtração, multiplicação e divisão) a partir da escolha do usuário. A calculadora será projetada para a entrada de 4 bits clássicos e utilizará displays de sete segmentos para mostrar o resultado ao usuário.

### Calculadora no MIPS
Este trabalho consiste em uma calculadora de números float programada para rodar em um processador de arquitetura MIPS que realiza as operações básicas de soma, subtração, multiplicação e divisão. Utilizando do driver MMIO para ler os dados do teclado e mostrar no display.
